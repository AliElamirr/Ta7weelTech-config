# Ta7weel Tech — اللينك الثابت

الأجهزة (AG App وآيفون) بتقرا `config.json` من اللينك ده عشان تعرف الموقع فين:

```
https://raw.githubusercontent.com/AliElamirr/Ta7weelTech-config/main/config.json
```

- `site`: الموقع الحالي. **لو نقلت الموقع، غيّر السطر ده بس** وكل الأجهزة تمشي وراه.
- `min_app_version`: أقل نسخة AG App مسموحة.

⚠️ الريبو ده **Public**: ماتحطش فيه أي باسورد أو مفتاح أبدًا.
